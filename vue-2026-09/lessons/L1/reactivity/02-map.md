# Map

## Кратко
Коллекция «ключ → значение», где **ключом может быть что угодно** (в отличие от объекта — там ключи только строки/символы). Сохраняет порядок вставки.

```js
const map = new Map();
map.set('name', 'Ann');
map.set(42, 'число');
map.set({ id: 1 }, 'ключ-объект'); // объект как ключ — можно!
```

## Методы и свойства

```js
map.set(key, value); // добавить/обновить
map.get(key);        // получить (undefined, если нет)
map.has(key);        // проверка
map.delete(key);     // удалить
map.size;            // размер
map.clear();         // очистить
```

## Перебор

```js
for (const [key, value] of map) console.log(key, value);
map.forEach((value, key) => console.log(key, value));

[...map.keys()];    // все ключи
[...map.values()];  // все значения
[...map.entries()]; // все пары
```

## Создание из массива

```js
const map = new Map([
  ['a', 1],
  ['b', 2],
]);
```

## Map vs Object

| | `Map` | `Object` |
|---|---|---|
| Тип ключей | любой | строка / символ |
| Порядок | гарантирован | с оговорками |
| Размер | `.size` | `Object.keys().length` |
| Частые add/delete | оптимизирован | менее удобно |

## Зачем для реактивности
Vue 3 хранит **связи «объект → его зависимости»** в `Map`, а изменения поддерживает через `Proxy`. `reactive(new Map())` и `.set()` / `.get()` работают реактивно — UI обновится при изменении содержимого.
