# Set

## Кратко
Коллекция **уникальных** значений любого типа (примитивы и объекты). Автоматически убирает дубликаты.

```js
const set = new Set([1, 2, 2, 3, 3, 3]);
console.log(set); // Set(3) { 1, 2, 3 }
```

## Методы и свойства

```js
set.add(4);        // добавить
set.has(2);        // true — проверка наличия
set.delete(1);     // удалить
set.size;          // количество элементов
set.clear();       // очистить всё
```

## Перебор

```js
for (const value of set) console.log(value);
set.forEach(v => console.log(v));
[...set]; // превратить в массив
```

## Частый приём: уникальность

```js
const unique = [...new Set([1, 1, 2, 3, 3])]; // [1, 2, 3]

const uniqueUsers = [...new Set(users.map(u => u.role))]; // список уникальных ролей
```

> `Set` хранит значения по ссылке: два одинаковых объекта — это **разные** элементы.

## Сравнение с массивом
- `has()` быстрее, чем `includes()` у большого массива (O(1) против O(n)).
- Нет доступа по индексу.

## Зачем для реактивности
Реактивные системы и `Set` используются для хранения **наборов зависимостей** (какие эффекты/компоненты зависят от значения). Vue 3 применяет `Set` внутри `dep`-коллекций реактивных эффектов, а `reactive(new Set())` поддерживает `.add()` / `.delete()` как реактивные мутации.
