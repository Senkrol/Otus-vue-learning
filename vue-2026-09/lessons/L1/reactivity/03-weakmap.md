# WeakMap

## Кратко
Коллекция «ключ → значение», где:
- **ключом может быть только объект** (или не-регистрируемый символ);
- ключи хранятся **слабо** (weak) и не мешают сборке мусора.

```js
const wm = new WeakMap();
const user = {};
wm.set(user, 'данные');
wm.get(user); // 'данные'
```

## Особенности

- ❌ **Нет** `size`, `keys()`, `values()`, `entries()`, `forEach()` — нельзя перебрать.
- ❌ Нельзя очистить целиком (`clear` отсутствует).
- ✅ Есть только `set`, `get`, `has`, `delete`.
- ✅ Если на объект-ключ больше нет ссылок — запись удаляется сборщиком мусора автоматически.

```js
let key = {};
const wm = new WeakMap();
wm.set(key, 'x');
wm.has(key); // true

key = null;  // объект потерял все ссылки → сборщик мусора удалит и ключ, и значение
```

## Зачем нужен
Хранение **приватных/служебных данных**, привязанных к объекту, без «утечек памяти»: когда объект исчезает, вместе с ним пропадает и связанная запись.

## WeakMap vs Map

| | `WeakMap` | `Map` | 
|---|---|---|
| Ключи | только объекты | любой тип |
| Перебор | ❌ | ✅ |
| `size` | ❌ | ✅ |
| Сборка мусора | не удерживает ключи | удерживает |

## Зачем для реактивности
Vue 3 и другие реактивные библиотеки используют `WeakMap`, чтобы хранить связи «сырой объект → его реактивный прокси». Это позволяет не удерживать объекты в памяти навсегда и повторно переиспользовать один и тот же прокси для одного и того же объекта.
